# 通用框架模板（提示词框架库）

收录提示词工程通用框架的完整写法与示例（课程 P4）。生成提示词前先按任务类型选型，再套用对应框架。

## 选型速查

| 任务类型 | 推荐框架 | 一句话说明 |
|---|---|---|
| 简单文案/总结 | RTF | 最简，角色 + 任务 + 格式 |
| 常规任务（有背景 + 素材） | ICIO | 指令 + 上下文 + 输入数据 + 输出指引 |
| 营销内容（小红书/抖音/广告） | CUSTOM | 背景 + 目标 + 风格 + 语调 + 受众 + 输出格式 |
| 复杂/专业/高要求 | CRISPE | 全要素覆盖，顶配 |
| 需要动脑推理 | COT | 逐步推理，给出思考过程 |
| 项目规划 | BROKE | 背景 + 角色 + 目标 + 关键结果 + 进化 |
| 营销转化（B2C） | AIDA | 吸引 → 兴趣 → 渴望 → 行动 |
| 高转化痛点营销（B2B） | PAS | 痛点 → 放大 → 方案 |

## 一、RTF 框架（通用万能 · 最简）

**结构**：角色(Role) + 任务(Task) + 格式(Format)

**适用**：写文案、做总结、简单生成等 80% 日常任务；复杂任务建议升级为 ICIO/CRISPE。

**完整写法**：

```
【角色】你是一名资深的<职业>，擅长<领域>。
【任务】请<动词>：<具体任务，写明给谁看、发在哪、什么主题>。
【格式】用<格式要求>输出，篇幅<限制>。
```

**示例（写朋友圈文案）**：

```
【角色】你是一名资深朋友圈运营，擅长生活化种草文案。
【任务】为一杯新出的桂花拿铁写一条朋友圈文案，发在个人朋友圈，面向 25-35 岁都市白领。
【格式】正文不超过 80 字，末尾加 3 个相关话题标签，纯文本。
```

## 二、ICIO 框架（通用万能 · 更全面）

**结构**：指令(Instruction) + 上下文(Context) + 输入数据(Input data) + 输出指引(Output guide)

**要点**：指令用动词开头、直接；输入数据必须给全，"输入质量决定输出质量"。

**完整写法**：

```
【指令】请<用动词开头，直接明确>。
【上下文】背景：<场景>；给谁看：<受众>；风格：<风格要求>。
【输入数据】<原始素材必须给全：文本/数据/参考样例>。
【输出指引】格式：<分几部分/是否加粗>；篇幅：<字数>；结构：<顺序>。
```

**示例（总结会议纪要）**：

```
【指令】请将以下会议记录整理成结构化纪要。
【上下文】背景：产品周会；给谁看：项目组全员；风格：简洁中性、突出结论。
【输入数据】<粘贴完整会议记录原文>。
【输出指引】分三部分输出：待办事项 / 关键决策 / 风险项；每项不超过 2 行。
```

## 三、CUSTOM 框架（内容创作专用）

**结构**：背景 + 目标 + 风格 + 语调 + 受众 + 输出格式

**适用**：营销文、小红书笔记、抖音文案等平台内容创作。

**完整写法**：

```
【背景】<品牌/产品/活动背景>。
【目标】<本次内容想达到的效果，如涨粉、转化、种草>。
【风格】<视觉/行文风格>。
【语调】<语气，如亲切、专业、幽默>。
【受众】<目标人群画像>。
【输出格式】<标题 + 正文结构 + 标签等>。
```

**示例（小红书种草）**：

```
【背景】新上市一款便携咖啡机，主打 30 秒出杯。
【目标】让读者产生购买欲，收藏笔记。
【风格】真实体验分享，含使用细节与对比。
【语调】亲切口语，像朋友推荐。
【受众】租房独居的 20-30 岁上班族。
【输出格式】标题（含关键词）+ 正文 5 段（痛点-开箱-体验-效果-推荐）+ 3 个话题标签。
```

## 四、CRISPE 框架（通用万能 · 顶配）

**结构**：背景 + 角色 + 指令 + 格式 + 语气 + 输出格式（含风格、受众、约束）

**适用**：覆盖所有场景，尤其复杂/专业/高要求任务。

**完整写法**：

```
【背景】<任务背景与上下文>。
【角色】你是一名<专业身份>。
【指令】请<明确任务>。
【格式】<输出结构要求>。
【语气】<语气要求>。
【输出格式】<风格、受众、约束、篇幅>。
```

**示例（生成产品分析报告）**：

```
【背景】公司计划进入智能家居市场，需要一份竞品分析。
【角色】你是一名资深市场分析师，熟悉智能家居行业。
【指令】分析市面上 3 款主流智能音箱的优劣势与定价策略。
【格式】按"市场概况 / 竞品对比 / 机会点 / 风险"四部分输出。
【语气】专业客观，数据支撑。
【输出格式】面向高管汇报，每部分 3-5 条要点，共 1000 字以内，不得编造数据。
```

## 五、COT 思维链（推理逻辑型）

**结构**：在任意框架基础上追加"逐步思考"指令

**适用**：要动脑的问题（数学、逻辑分析、复杂推理），防止 AI 跳步出错。

**完整写法**：

```
<任务描述>

请一步步思考，把推理过程详细写出来，确保每一步都符合逻辑和常识；遇到复杂计算就分步计算，完成所有推导后再给出最终答案。
```

**变体**：
- **零样本思维链**：不加示例，直接追加上述指令
- **自洽思维链**：让 AI 用不同思路多算几遍，选出出现次数最多的答案，减少单次偶然错误

## 六、BROKE 框架（项目规划型）

**结构**：背景(Background) + 角色(Role) + 目标(Objective) + 关键结果(Key results) + 进化(Evolve)

**适用**：项目规划、方案设计、需要多轮迭代的任务。

**完整写法**：

```
【背景】<项目背景与现状>。
【角色】你是一名<专业身份>。
【目标】<最终目标>。
【关键结果】<可衡量、可验收的结果指标>。
【进化】<基于首次输出不断追问修正，深化迭代>。
```

**示例（读书计划）**：

```
【背景】我想三个月内系统学习 AI 产品设计。
【角色】你是一名 AI 产品导师。
【目标】制定可执行的三个月学习计划。
【关键结果】每月产出一个可验收成果：1 份竞品拆解报告 / 1 个 MVP 方案 / 1 次用户访谈总结。
【进化】先给整体框架，我再针对每周细节继续追问细化。
```

## 七、AIDA 框架（创作营销型）

**结构**：吸引注意力(Attention) → 激发兴趣(Interest) → 唤起渴望(Desire) → 促使行动(Action)

**适用**：B2C 营销文案、广告、推广内容。

**完整写法**：

```
【A 吸引】用<钩子>抓住注意力（惊人数据/反常识/痛点共鸣）。
【I 兴趣】用<细节>激发兴趣（场景代入/故事/对比）。
【D 渴望】用<好处>唤起渴望（价值点/证据/稀缺感）。
【A 行动】用<行动指令>促使行动（点击/下单/私信）。
```

## 八、PAS 框架（创作营销型 · 高转化）

**结构**：痛点(Problem) + 放大(Aggravate) + 方案(Solution)

**适用**：B2B 文案、高转化落地页，直戳真实痛点。

**完整写法**：

```
【P 痛点】点出问题：<直戳真实痛点，描述目标用户的困境>。
【A 放大】放大痛苦：<不解决会带来什么后果，把隐性焦虑变显性紧迫感>。
【S 方案】给出方案：<产品怎么解决 + 具体好处 + 行动指令>。
```

## 九、高阶框架速览（了解即可）

| 框架 | 一句话说明 | 适用 |
|---|---|---|
| TOT 思维树 | 生成多个思路 → 剪掉不对的 → 深入推导 → 重复到解决 | 复杂开放问题 |
| ReAct 框架 | 思考 + 行动循环，可搜索/计算/调工具 | 需调用外部工具的复杂任务 |
| GoT 图思考 | 节点 + 关系网状结构 | 多实体多关系复杂问题 |
| RAG 增强生成 | 先查资料再作为上下文喂给模型 | 根治胡说八道，接私域知识库 |
