# 图片生成提示词模板

适用工具：Midjourney、Stable Diffusion、即梦图片、DALL·E 等图片生成类 AI。
核心结构：正向提示词 + 负向提示词，纯文本可粘贴。

## 模板骨架（通用）

```
【正向提示词】
<主体>，<构图>，<风格>，<光线色调>，<细节描述>，<画幅比例>

【负向提示词】
<模糊、畸变、多余物体、低质量等>
```

## 框架选型建议（课程 P4）

| 场景 | 推荐框架 | 说明 |
|---|---|---|
| 单张插画/照片 | RTF / ICIO | 角色=美术指导，输入数据=主体完整描述，输出指引=正向+负向 |
| 商业海报/营销图 | CUSTOM | 背景+目标+风格+语调+受众+输出格式 |
| 高要求概念图 | CRISPE + COT | 先分解画面要素（主体/构图/光线/细节）再逐项组装 |

## 进阶技术应用（课程 P5）

- **格式强制**：正向词严格按"主体 → 构图 → 风格 → 光线 → 细节 → 比例"顺序输出
- **约束提示**：画红线（禁止多余肢体、文字乱码、水印等），负向提示词必须提供
- **少样本**：用户有满意旧图时，给 1 个样例锁定风格
- **自我修正**：先出草稿版本，再对照要素清单补漏打磨

## 分项填写指南

| 分项 | 说明 | 示例 |
|---|---|---|
| 主体 | 画面核心对象 | 一只橘猫趴在窗台 |
| 构图 | 视角与布局 | 居中构图、俯拍、特写 |
| 风格 | 流派与质感 | 水彩插画 / 赛博朋克 / 电影剧照 / 3D渲染 |
| 光线色调 | 氛围来源 | 黄昏暖光、冷蓝月光、柔和漫射光 |
| 细节 | 加分元素 | 毛发光泽、窗外雨滴、前景虚化 |
| 画幅比例 | 尺寸关键词 | 1:1 / 16:9 / 3:4 / 9:16 |

## 完整示例（赛博朋克城市）

```
【正向提示词】
雨夜霓虹下的未来城市街道，一个穿透明雨衣的行人背影，居中构图，赛博朋克风格，冷蓝与品红霓虹光交映，湿润路面反射灯光，前景雨滴虚化，远处高楼全息广告牌，电影级光影，8K细节，16:9

【负向提示词】
模糊、畸变、多余肢体、文字乱码、低质量、噪点、水印
```

## 自动化评估维度（课程 P6，供批量生成时打分）

| 维度 | 图片场景考察点 |
|---|---|
| 准确性 | 主体、风格、光线是否符合描述 |
| 可控性 | 是否按指定顺序输出正向词、负向词是否到位 |
| 完整性 | 正向 + 负向 + 画幅比例是否齐全 |
| 稳定性 | 换主体、换风格后提示词是否依然可用 |

## 风格速查

| 用户要 | 风格词 |
|---|---|
| 真实照片 | 摄影写实、浅景深、自然光影、胶片颗粒 |
| 插画 | 水彩、扁平插画、儿童绘本 |
| 3D | 皮克斯风格、3D渲染、柔光 |
| 国风 | 水墨、工笔、青绿山水 |
| 科幻 | 赛博朋克、废土、太空歌剧 |

## 要点速查

| 项 | 要求 |
|---|---|
| 正向词 | 主体→构图→风格→光线→细节→比例，顺序写 |
| 负向词 | 必须提供，默认含"模糊、畸变、低质量" |
| 比例 | 用户没指定时默认 1:1 并说明 |
