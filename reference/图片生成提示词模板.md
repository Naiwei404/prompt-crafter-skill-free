# 图片生成提示词模板

适用工具：Midjourney、Stable Diffusion、即梦图片、DALL·E 等图片生成类 AI。
核心结构：正向提示词 + 负向提示词，纯文本可粘贴。

## 模板骨架（通用）

```
【正向提示词】
<主体>，<构图>，<风格>，<光线色调>，<细节描述>，<画幅比例>

【负向提示词】
<模糊、畸变、多余物体、低质量等>
```

## 分项填写指南

| 分项 | 说明 | 示例 |
|---|---|---|
| 主体 | 画面核心对象 | 一只橘猫趴在窗台 |
| 构图 | 视角与布局 | 居中构图、俯拍、特写 |
| 风格 | 流派与质感 | 水彩插画 / 赛博朋克 / 电影剧照 / 3D渲染 |
| 光线色调 | 氛围来源 | 黄昏暖光、冷蓝月光、柔和漫射光 |
| 细节 | 加分元素 | 毛发光泽、窗外雨滴、前景虚化 |
| 画幅比例 | 尺寸关键词 | 1:1 / 16:9 / 3:4 / 9:16 |

## 完整示例（赛博朋克城市）

```
【正向提示词】
雨夜霓虹下的未来城市街道，一个穿透明雨衣的行人背影，居中构图，赛博朋克风格，冷蓝与品红霓虹光交映，湿润路面反射灯光，前景雨滴虚化，远处高楼全息广告牌，电影级光影，8K细节，16:9

【负向提示词】
模糊、畸变、多余肢体、文字乱码、低质量、噪点、水印
```
