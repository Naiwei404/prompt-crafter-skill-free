# 视频生成提示词模板

适用工具：可灵、即梦、Seedance、Sora、Runway 等视频生成类 AI。
核心偏好：逐秒精细 + 纯文本可粘贴版。

## 模板骨架

```
【视频提示词 · 总时长 5s】
风格统一：写实探店 / 电影质感 / 赛博朋克 / 动画风...

[0-1s] 镜头语言 + 画面内容
[1-2s] 镜头语言 + 画面内容
[2-3s] 镜头语言 + 画面内容
[3-4s] 镜头语言 + 画面内容
[4-5s] 镜头语言 + 画面内容

【负向提示词】变形、多余肢体、模糊、文字乱码...
```

## 框架选型建议（课程 P4）

| 场景 | 推荐框架 | 说明 |
|---|---|---|
| 简单镜头脚本 | RTF | 角色=导演/分镜师，任务=逐秒分镜，格式=[X-Ys] 镜头+内容 |
| 探店/美食/营销视频 | CUSTOM | 背景+目标+风格+语调+受众+输出格式，最贴合种草场景 |
| 复杂长片/高要求 | CRISPE | 全要素覆盖，含风格、受众、约束 |
| 需逻辑连贯 | 叠加 COT | 按时间轴逐步推导每段镜头逻辑，避免跳戏 |

## 进阶技术应用（课程 P5）

- **格式强制**：明确"按 [X-Ys] 格式输出每段，每段不超过 30 字"，不给模型自行发挥空间
- **约束提示**：负向提示词必须提供；限制时长、镜头数量、禁止变形
- **自我修正**：生成后自检"动作是否连贯、镜头语言是否交代清楚、是否漏段"，有问题先改再定稿

## 动作细化黄金法则（图生视频/食物开箱类）

1. **拆慢动作链**：单句动作 → 2~3 步有承接关系的连贯动作
   - 错误："拆开汉堡包装"
   - 正确："揭开封口 → 翻纸露面包胚 → 双手挤咬口出层次"
2. **补现场感细节**：撕纸声、热气、油光、面包屑、掉屑
3. **动作幅度小幅**：避免剧烈动作导致画面变形
4. **交代镜头语言**：缓推 + 怼近切面，不让模型自己想象
5. **避开易变形动作**：挤咬口、渗汤汁、大幅甩动

## 完整示例（5s 探店拆汉堡）

```
【视频提示词 · 总时长 5s】
风格统一：手机实拍探店质感，暖色调，浅景深

[0-1s] 固定机位近景：双手捏住汉堡纸包装封口，指尖微微用力
[1-2s] 顺着折痕缓缓撕开封口，发出轻微的撕纸声，包装纸边缘轻微抖动
[2-3s] 翻纸露出面包胚表面，芝麻粒清晰可见，表面冒着热气
[3-4s] 镜头缓推怼近切面：面包、生菜、肉饼层次分明，油光发亮
[4-5s] 双手轻轻挤向咬口位置，肉汁微微渗出，镜头定格

【负向提示词】手指变形、汉堡散架、剧烈晃动、画面模糊、文字乱码
```

## 自动化评估维度（课程 P6，供批量生成时打分）

| 维度 | 视频场景考察点 |
|---|---|
| 准确性 | 画面是否符合主题与风格统一 |
| 可控性 | 是否严格按逐秒结构输出、镜头语言是否交代 |
| 完整性 | 是否覆盖全部时间段、负向提示词是否齐全 |
| 稳定性 | 换主体/换时长是否依然结构清晰、动作不跳戏 |

## 要点速查

| 项 | 要求 |
|---|---|
| 分段 | 逐秒或按节奏分段，每段写清"镜头 + 内容" |
| 动作 | 拆慢动作链，给落点与轨迹 |
| 细节 | 补感官细节增强真实感 |
| 负向词 | 必须提供，防变形防糊 |
