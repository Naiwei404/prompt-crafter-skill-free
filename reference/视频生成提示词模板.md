# 视频生成提示词模板

适用工具：可灵、即梦、Seedance、Sora、Runway 等视频生成类 AI。
核心偏好：逐秒精细 + 纯文本可粘贴版。

## 模板骨架

```
【视频提示词 · 总时长 5s】

[0-1s] 镜头语言 + 画面内容

[2-3s] 镜头语言 + 画面内容
[3-4s] 镜头语言 + 画面内容
[4-5s] 镜头语言 + 画面内容

【负向提示词】变形、多余肢体、模糊、文字乱码...
```

## 动作细化黄金法则（图生视频/食物开箱类）

1. **拆慢动作链**：单句动作 → 2~3 步有承接关系的连贯动作
   - 错误："拆开汉堡包装"
   - 正确："揭开封口 → 翻纸露面包胚 → 双手挤咬口出层次"
2. **补现场感细节**：撕纸声、热气、油光、面包屑、掉屑
3. **动作幅度小幅**：避免剧烈动作导致画面变形
4. **交代镜头语言**：缓推 + 怼近切面，不让模型自己想象
5. **避开易变形动作**：挤咬口、渗汤汁、大幅甩动

## 完整示例（5s 探店拆汉堡）

```
【视频提示词 · 总时长 5s】
风格统一：手机实拍探店质感，暖色调，浅景深

[0-1s] 固定机位近景：双手捏住汉堡纸包装封口，指尖微微用力
[1-2s] 顺着折痕缓缓撕开封口，发出轻微的撕纸声，包装纸边缘轻微抖动
[2-3s] 翻纸露出面包胚表面，芝麻粒清晰可见，表面冒着热气
[3-4s] 镜头缓推怼近切面：面包、生菜、肉饼层次分明，油光发亮
[4-5s] 双手轻轻挤向咬口位置，肉汁微微渗出，镜头定格

【负向提示词】手指变形、汉堡散架、剧烈晃动、画面模糊、文字乱码
```
