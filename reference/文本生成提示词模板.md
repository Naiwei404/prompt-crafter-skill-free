# 文本生成提示词模板

适用工具：ChatGPT、Claude、DeepSeek、豆包等对话式文本生成 AI。
核心结构：角色设定 + 任务目标 + 输出要求 + 风格约束，纯文本可粘贴。

## 模板骨架（通用）

```
【角色设定】AI 扮演的角色与专业背景

【任务目标】要完成的具体任务（越具体越好）

【输出要求】格式、篇幅、结构、语言

【风格约束】语气、目标读者、禁忌项

【示例】（可选）给一个参照样例
```

## 分项填写指南

| 分项 | 说明 | 示例 |
|---|---|---|
| 角色设定 | 让 AI 进入专业身份 | 资深小说编辑、Python 开发专家 |
| 任务目标 | 一句话说清要什么 | 写一个悬疑小说开头 500 字 |
| 输出要求 | 可验收的硬指标 | 3 个段落、含悬念钩子、纯文本 |
| 风格约束 | 语气与边界 | 口语化、面向大学生、不剧透 |
| 示例 | 参考样板 | 给一段你满意的旧文 |

## 完整示例（写小说开头）

```
【角色设定】你是擅长悬疑题材的资深小说编辑，熟悉网文节奏与钩子设计

【任务目标】为一个都市悬疑短篇写第一章开头，500 字左右，主角是一名失眠的夜班便利店店员

【输出要求】3 个自然段；第一段建立氛围，第二段引入异常事件，第三段留下悬念；纯文本输出，不用标题

【风格约束】冷峻克制的叙述语气，短句为主，第一人称；面向 18-30 岁网文读者；不要出现超自然解释

【示例】参考《漫长的季节》式冷调开场
```

## 场景速查

| 用户要 | 角色设定建议 | 关键输出要求 |
|---|---|---|
| 小说/故事 | 小说作者、网文编辑 | 字数、视角、段落数、钩子 |
| 文案/营销 | 资深文案、品牌策划 | 平台、字数上限、转化目标 |
| 代码 | 资深工程师 | 语言、框架、输入输出、注释要求 |
| 报告/论文 | 学术编辑、领域专家 | 结构、引用格式、篇幅 |
| 日常问答 | 通用助手 | 简洁/详细、是否给步骤 |

## 要点速查

| 项 | 要求 |
|---|---|
| 任务目标 | 必须具体可验收，避免"写点东西"式模糊 |
| 输出要求 | 硬指标写清：字数/段落/格式 |
| 风格约束 | 语气 + 读者 + 禁忌三件套 |
| 示例 | 有样例时质量显著提升，能提供就提供 |
