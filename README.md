# prompt-crafter（提示词大师）

从零撰写 AI 提示词的专业 Skill，支持**视频生成、图片生成、文本生成**三大类。工作模式为"反问澄清 → 按类型生成 → 纯文本交付 → 局部可修改"，并支持框架化生成与自动化批量生成。

## 特性

- **五大基本结构**：角色 / 任务 / 技能 / 输出格式 / 条件与限制，覆盖完整提示词骨架
- **八大框架库**：RTF、ICIO、CUSTOM、CRISPE、COT、BROKE、AIDA、PAS 全套写法与示例，按场景选型
- **进阶技术**：零样本 / 少样本 / 单样本、思维链、格式强制、约束提示、自我修正、复述确认、多轮拆解等
- **自动化生成模式**：元提示词模板 → 批量变体 → 四维自动评估（准确性 / 可控性 / 完整性 / 稳定性）→ 迭代优化
- **安全防御**：生成提示词时内置防注入加固（强指令声明、末尾指令覆盖、敏感信息保护约束）

## 安装

### 方式一：直接导入（推荐）

将本仓库 `prompt-crafter-skill` 目录（或发布包 zip）导入支持 SKILL.md 的 AI 工具（如 WorkBuddy / Claude Code / ClawdHub 等）。

### 方式二：手动复制

把以下目录/文件放入你的 Skills 目录：

```
prompt-crafter-skill/
├── SKILL.md                      # 技能定义与元信息
├── instructions.md               # 执行细则（反问协议 + 生成规范 + 自动化 + 安全防御）
└── reference/
    ├── 通用框架模板.md            # 八大框架完整写法与示例
    ├── 视频生成提示词模板.md      # 视频类生成规范
    ├── 图片生成提示词模板.md      # 图片类生成规范
    └── 文本生成提示词模板.md      # 文本类生成规范
```

## 使用方法

1. 说出触发词：**prompt-crafter / 提示词大师 / 写提示词 / 生成提示词**，并描述你的粗略想法
2. 技能会先反问澄清需求（用途、类型、主题、风格、篇幅等），直到自评置信度 ≥ 95% 才生成
3. 按类型生成完整提示词，交付**纯文本可粘贴版**，可直接复制进目标 AI 工具
4. 对不满意的局部提出修改，技能只深化指定局部，保留其余骨架

### 示例

- "写提示词：做一个 5 秒的产品宣传视频，赛博朋克风"
- "提示词大师，帮我写小红书文案的提示词"
- "生成提示词：把这段周报改成正式的商务邮件"
